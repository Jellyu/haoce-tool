# release 目录说明

| 路径 | 内容 |
| --- | --- |
| `haoce-tool-green/` | 绿色版目录（可浏览），解压即用 |
| `haoce-tool-green.zip` | 绿色版完整压缩包（**推荐下载**） |

## 关于 `bin/ffmpeg.exe`

绿色版里的 `bin/ffmpeg.exe` 约 100.5 MB，超过 GitHub 单文件 100 MB 的硬限制，
因此**没有纳入 git 跟踪**，仓库里的 `haoce-tool-green/` 默认缺少这个文件。

需要完整可运行版本时，请下载本页的 `haoce-tool-green.zip`，或在
[Releases](https://github.com/Jellyu/haoce-tool/releases) 页面下载对应版本的绿色版压缩包。
